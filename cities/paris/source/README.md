# Paris source

The generated map data in `../addresses.json` is derived from the City of Paris
Open Data dataset **Programmes de logements sociaux financés à Paris**.

- Source: https://opendata.paris.fr/explore/dataset/logements-sociaux-finances-a-paris/
- Coverage: programmes financed since 2001
- Retrieved: 2026-10-12
- Licence: ODbL

The 4,293 source programme records were consolidated to 3,876 map locations only
when their address, provider and coordinates coincided. Aggregated source-record
count, finance years and total homes remain in the exported data.
